# Round 47, добавление: «в списках только коды (нет в справочнике)»

## Диагноз

Не баг в коде — ожидаемое и уже задокументированное состояние
(`docs/round47-qgis-plugin.md`, блок A2, раздел "Не сделано").

Плагин берёт названия районов/областей с файла
`https://geobotany.of.by/districts_ref.json` (подготовлен в round47,
генерируется из `REPIKURR/repikurr/src/constants.js`). Этот файл
существует только **локально в репозитории**
(`REPIKURR/repikurr/public/districts_ref.json`) — на сам прод он ещё
не попадал, потому что это требует выкатки фронтенда, а выкатка на
прод в этом раунде намеренно не выполнялась без вашего подтверждения.

Проверено фактом прямо сейчас:
```
curl https://geobotany.of.by/districts_ref.json
  -> HTTP 200, Content-Type: text/html   (это index.html фронтенда —
     файла нет, сервер отдаёт SPA-заглушку по правилу try_files)
```
Плагин корректно распознаёт это как отказ (не JSON) и делает именно то,
что задумано для такого случая — показывает код без названия с
пометкой «нет в справочнике», вместо падения. То есть сработал не баг,
а штатный fallback на неполный, но не задеплоенный источник.

## Исправление

Кода менять не нужно. Нужен деплой фронтенда — тот самый пакет,
который уже был подготовлен и описан в `docs/round47-qgis-plugin.md`,
раздел "Пакет действий на подтверждение пользователя", пункт 1:

```bash
# на координаторской машине, из корня репозитория
./REPIKURR/deploy_frontend_vps.sh
```

Скрипт сам прогонит `smoke.mjs` в конце (уже проверено — 21/22 шагов
зелёные на текущем проде, единственный красный — именно 13b,
контрольная сумма архива плагина, ровно по той же причине: новый
пакет ещё не на проде). После успешного деплоя ожидается 22/22, а
названия районов/областей в плагине появятся без дополнительных
действий — как только страница отдаёт настоящий `districts_ref.json`
вместо `index.html`.

## Что нужно от вас

Подтвердите деплой фронтенда — я не выполняю его сам без явного
разрешения (правило проекта: не выкатывать на прод без подтверждения).
После вашего "да" я запущу `deploy_frontend_vps.sh` и сообщу результат
прогона `smoke.mjs`.
