какой результат ожидается **на эталоне**, и какая автоматическая проверка это
покрывает. Источники — код фронтенда (`REPIKURR/repikurr/src/…`), код плагина
(`pikurr_qgis/…`), тесты (`REPIKURR/tools/smoke/smoke.mjs`,

эталонные числа — из отчётов раундов 48–49 (ссылки ниже), **в раунде 51 на
живом проде не пересчитывались** (правило раунда 51 — не менять/не
нагружать прод; эти два числа помечены «из отчёта»). Сокращения:
`SB` = `REPIKURR/repikurr/src/components/Sidebar.jsx`, `APP` =
`REPIKURR/repikurr/src/App.jsx`, `MV` = `…/components/MapView.jsx`,
`PL` = `pikurr_qgis/pikurr.py`, `SMK` = `REPIKURR/tools/smoke/smoke.mjs`,
`E2E` = `pikurr_qgis/tests/test_plugin_e2e.py`, `HL` =

## А. Витрина (`https://geobotany.of.by`)

Интерфейс — левая боковая панель «ПИК УРР — Оценка сельскохозяйственных
угодий» и карта (Leaflet); стартовый вид — зум 9 (`MV:293`). Порядок и
подписи элементов — `SB:122-287`.

## Б. Плагин QGIS `pikurr` v1.2.0 (`pikurr_qgis/`)

Установка — «Модули → Управление модулями → Установить из ZIP»
(`legacy-diff.md`, ОП 2.2.2). QGIS 3.44+ (`metadata.txt`). Плагин
открывает **панель** «ПИК УРР» (`QDockWidget`, не блокирует карту;
`pikurr_panel_base.ui`, `E2E` шаг 0). Сервер по умолчанию — прод по HTTPS
(`metadata.txt`, about; настраивается в разворачиваемом блоке «▸ Настройки
сервера»).

| # | Сценарий | Ожидаемый результат | Покрытие |
|---|---|---|---|
| Б1 | **Открыть панель**, подключиться к серверу | Строка состояния «Сервер: … — данные загружены…» (`PL:237`); при недоступном сервере — «Сервер недоступен: …» без исключения (`PL:207`) | `HL` 1 (сервер доступен по содержимому — WPS `GetCapabilities`), `E2E` 6a/6b/6c (недоступный адрес, не-GeoServer, мусорный ответ — панель жива) |

Примечания:

- `test_headless.py` и `test_plugin_e2e.py` требуют доступа к боевому серверу
  (`HL` шапка: «против реального прод-сервера, без моков») и QGIS 3.44 на
  машине запуска; как запускать — `test-methods.md`.
- Автоматические проверки плагина не покрывают реальный GUI на экране
  (`QT_QPA_PLATFORM=offscreen`), а ключевые визуальные шаги (видимость AI-слоя
  на карте, копирование в Excel, смена подложки) отнесены к ручной проверке
  пользователем (`docs/round48-qgis-plugin.md`, п. 5–7).
- Статус плагина в метаданных — `experimental=True`; текст
  `pikurr_qgis/PROTOTYPE_NOTICE.md` устарел относительно 1.2.0
  (`operations.md`, §4).
