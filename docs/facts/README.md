# Фактическая база для документации (раунд 51)

Нейтральные факты о текущей системе PIKURR/REPIKURR со ссылками на
источники (файл:строка, команда и дата, раздел `system-state.md`). Не
документы по ГОСТ 19 — сырьё для них. Отчёт раунда — `../round51-docs-facts.md`.
Старые документы (декабрь 2024) в репозиторий не входят (`docs/_legacy_local/`
в `.gitignore`).

| Файл | Тема |
|---|---|
| `legacy-diff.md` | сверка старого комплекта (ОП, РО, ПМИ, ВНЗ) с текущей системой; обязательные проверки по коду; ошибки старого комплекта |
| `etl-route.md` | технологический маршрут ETL по задачам: входы/выходы, параметры, порядок, что видит оператор |
| `data-io.md` | входные и выходные данные: слои, таблицы, растры, пакет обновления 2.1, слои GeoServer, служебные JSON |
| `hardware-software.md` | технические средства и ПО: стенд ETL, сервер витрины, рабочее место; объёмы данных |
| `operations.md` | указатель сценариев эксплуатации и типовых сбоев |
| `user-scenarios.md` | сценарии пользователя (витрина, плагин QGIS), эталон, покрытие тестами |
| `test-methods.md` | автоматические проверки, критерии, запуск, пробелы покрытия ETL |
| `source-deposit.md` | проект состава исходных текстов носителя; что включать нельзя; веса моделей |

Правило: утверждение без источника помечено «не подтверждено»; числа
машин (стенд, VPS, координатор) не смешиваются.
