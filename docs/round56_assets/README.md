# round56 — скрипты (только чтение)

Запуск расчётов внутри контейнера `etl` на стенде: `cat lib.py <скрипт>.py | ssh <стенд> 'docker exec -i pikurr-system-etl-1 python3 -' > результат.jsonl`
(`lib.py` — общая часть: пути, площадь на эллипсоиде, привязка растра к глобальной пиксельной сетке z17). Скрипты с суффиксом `_agg` / `a1_fields` / `a4_wms` / `a3b_parts`-агрегаторы — локальные, читают результаты `*.jsonl` и пакеты A/B (каталоги `A/`, `B/` с `vectors.gpkg`, как в `docs/round55_assets`; `calc.py` лежит рядом).

| скрипт | блок |
|---|---|
| `a1_geom.py`, `a1_agg.py`, `a1_fields.py`, `a1_pix.py` | A1: охват растров против полигонов, перекрытие, участки в зонах перекрытия, подтверждение чтением пикселей |
| `a2_pairs.py`, `a2_agg.py`, `a2_tiles.py` | A2.1–A2.2: согласие листов в перекрытии, матрица классов, расстояние до края, идентичность снимков |
| `a2_mask.py`, `a2_all.py`, `a2_bb.py`, `a2_geo.py` | A2.3: маска обработки (растяжение usab на холст в `classify.py`) |
| `a3_own.py`, `a3_agg.py`, `a3b_parts.py`, `a3b_agg.py` | A3: вариант «свой лист» |
| `a4_public.py`, `a4_wms.py` | A4: перекрытие публичных растров, ответ WMS на проде |
| `e2_load.sh`, `e2_run.sh`, `e2_export.sh` | E2: проверка неизменности расчёта (временный PostGIS на стенде) |
| `check_docs.py` | D: проверки комплекта документов |
