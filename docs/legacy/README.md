# Неиспользуемые варианты

## `nginx.vps.conf.template` (round21, B2)

Вариант фронтального прокси/TLS на nginx + certbot, подготовленный в
раунде 21. **Не используется** — раунд 22 заменил его на Caddy
(`REPIKURR/Caddyfile`, `docker-compose.vps.yml`) по причине, изложенной в
ТЗ round22: на прерываемой ВМ связка nginx+certbot требует отдельного
клиента, cron-продления и bootstrap-порядка для первичной выдачи
сертификата, причём окно продления может попасть на период простоя. Caddy
получает и продлевает сертификаты сам при каждом старте.

Файл сохранён для истории решения, не удалён по прямому указанию ТЗ round22
("Не делать: не удалять конфигурацию nginx/certbot из раунда 21").
