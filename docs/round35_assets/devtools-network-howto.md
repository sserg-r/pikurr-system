# Как посмотреть долю сети в загрузке карты (для пользователя)

Это займёт пару минут. Нужно, чтобы понять, сколько времени при
загрузке карты уходит на саму сеть (её мы почти не контролируем), а
сколько — на сервер (это уже можно чинить).

1. Открыть https://geobotany.of.by в браузере.
2. Открыть инструменты разработчика: `F12`, либо `Ctrl+Shift+I`
   (Windows/Linux) / `Cmd+Option+I` (Mac).
3. Перейти на вкладку **Network** (Сеть).
4. Обновить страницу (`Ctrl+R` / `Cmd+R`) — важно, чтобы DevTools уже
   были открыты в момент обновления, иначе запросы не запишутся.
5. Включить слой «AI оценка» в панели слева, если он ещё выключен.
6. В списке запросов найти строку поиска (обычно сверху списка) и
   вписать `wms` — останется только нужные запросы к карте.
7. Кликнуть на любой из них.
8. Справа откроется панель с деталями запроса — выбрать вкладку
   **Timing**.
9. Сделать скриншот этой вкладки целиком (там будет разбивка вида
   `Queueing`, `Stalled`, `DNS Lookup`, `Initial connection`,
   `Request sent`, `Waiting (TTFB)`, `Content Download`).

Прислать: скриншот из пункта 9, и лучше ещё словами — сколько
миллисекунд показано напротив `Initial connection` и сколько напротив
`Waiting`.

Это всё — большего не нужно.
