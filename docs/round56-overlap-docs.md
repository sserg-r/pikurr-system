### A2. Природа расхождений в перекрытии

Охвачены **все 3 224 пары** (требовалось ≥ 30) и все 182 участка с `max|Δ|` > 0,3 из раунда 55. Сравнение по глобальной сетке z17 — пиксель в пиксель, без передискретизации; «свой» лист — тот, в чей полигон `razgrafka` попадает пиксель, «чужой» — другой (сравнено 2 727 384 496 пикселей, лежащих в полигоне ровно одного из двух листов; ещё 160 млн — вне обоих полигонов, 150 тыс. — в обоих, в расчёт не вошли).

Снимки в перекрытиях побайтно одинаковы в **97,98 %** тайлов (43 169 из 44 061; различаются 892 тайла в 93 парах — листы, переведённые на другой источник); для пар без различающихся тайлов расхождение 14,49 % (сегментация 6,94 %) — то есть расхождение не из-за разных снимков.

Зависимость есть, но **слабая**: у самого края 17,1 % против ~14,2 % в середине полосы; расхождение велико на всём протяжении перекрытия. Гипотеза «расхождения — в основном краевой эффект холста» **не подтверждена**: вдали от края (100–199 пикс) расхождение 14,2 % при тех же снимках.

**A2.3. Маска обработки.** Из различий итогового растра **50,6 % — «только маска»** (сегментация листов совпала, различается класс 3 против 5), **49,4 % — различается сегментация**; различия с участием класса 5 составляют 62,0 % всех, из них 81,5 % — чисто маска. Найдена причина, специфичная для маски (`classify.py`, `usability.py`):

- растр `usab` (10 м) каждого листа покрывает **bbox полигона листа** (`usability.py:get_trapeze_bbox`): границы совпадают с bbox полигона с точностью ≤ 10 м (один пиксель) у всех 912 листов; холст листа (по целым тайлам) больше bbox на 0–255 пикс с каждой стороны;
- `classify.py` приводит маску к размеру холста `resize(combined_usab, land_mask_data.shape)` — то есть **растягивает маску размера bbox на весь холст**, без учёта геопривязки (воспроизведено: итоговый растр совпал побитно, 0 различающихся пикселей, на 4 листах). Следовательно, **за пределами bbox своего листа (полоса перекрытия «чужого» листа) данных Sentinel-2 у листа нет** — класс 5 там получен растяжением маски из другой части листа;
- масштаб смещения (912 листов): положение края маски относительно холста — медиана |лево| 127 пикс, |верх| 93 пикс, максимум по листу — медиана 214 пикс (≈145 м), до 254 пикс (≈172 м) (0,68 м/пикс);
- доля пикселей внутри полигона, где «растянутая» маска не совпадает с маской, посаженной по геопривязке: медиана **12,0 %** (p25 6,7 %, p75 17,4 %, p90 21,9 %, максимум 36,3 %); доля маски обработки в среднем 30,56 % против 28,28 % (×1,08).

Прямая проверка причинности по соседям не удалась: при посадке маски по геопривязке расхождение пар **растёт** (30,0 % против 14,4 % на 60 парах), так как в полосе «чужого» листа маски по геопривязке нет вовсе (данных нет), т. е. маска чужого листа в перекрытии не несёт независимой информации. **Не установлено:** какая посадка маски (растянутая или по геопривязке) соответствует действительности на местности — по снимкам или полевым данным это не проверялось; измерена только разница между двумя способами.

Оставшиеся 49,4 % различий — сегментация: 7,3 % пикселей перекрытия при побайтно одинаковых снимках; зависимость от края слабая (9,8 % у края, 6,6–6,8 % в середине). **Не установлено**, что именно в модели даёт эти 7 % (положение окон нарезки 256 с перекрытием 30 относительно начала холста у соседей разное; не проверялось).

**Контроль (1 лист, выборка 600): «свой лист» = A = B = ETL-функция полностью** (max|Δ| = 0 у 600 из 600; расчёт корректен).

Смена рекомендуемого сценария (`valuation`, правило раунда 55) из 6 791: «свой лист» ≠ A у **68** (1,0 %), «свой лист» ≠ B у 72, A ≠ B у 72; A→«свой лист»: clearing→meadow 28, meadow→clearing 23, forest→meadow 9, meadow→forest 6, clearing→tillage 1, tillage→clearing 1. Порядок листов (600 участков на 2+ листах, ETL-функция в порядке листов по возрастанию и по убыванию): результаты двух порядков совпадают только у 9 из 600 (1,5 %); A совпал с одним из двух порядков у 575 (95,8 %), B — у 576; «свой лист» отличается от обоих порядков медианой ~0,012. ### A5. Вывод по измерениям

- **Масштаб:** 7 484 участка на 2+ листах (13,4 % участков; 117 894 га, 32,5 % их площади), в зоне перекрытия растров — 27 039 га (22,9 % площади этих участков; 7,4 % площади всех участков). - **Природа:** (1) маска обработки — растягивание `usab` (bbox листа) на больший холст в `classify.py`: 51 % различий пикселей в перекрытии; в «чужой» полосе данных Sentinel-2 у листа нет; смещение маски до ≈ 170 м, медиана доли несовпадения с геопривязкой 12 %; (2) сегментация — 49 % различий (7,3 % пикселей) при одинаковых снимках; краевой эффект холста слабый (17 % у края против 14 % в середине); (3) порядок листов в `merge` — механизм, превращающий (1) и (2) в различие `stats`.
- **Какой из вариантов ближе к значениям «изнутри» листа:** по участкам на 2+ листах ни A, ни B (A ближе у 1 891, B — у 1 685, поровну 3 215); оба одинаково отстоят от «свой лист» (среднее `max|Δ|` 0,040 и 0,043).
- **Карта затронута:** да (A4).

**Варианты правки — только описание, не выполнялись:**

1. **`ORDER BY` в `get_fields`** (`save_db.py:34-45`: `array_agg(n10000 ORDER BY n10000)`) — детерминированность без качества: результат фиксируется (один из двух порядков), `stats` не становятся ближе к значениям «изнутри».
