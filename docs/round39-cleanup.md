### C2. Исправление

**Сделано**: `watchdog.py` — новая функция `_is_stable()`: файл
подхватывается только если его размер не изменился между двумя
замерами с паузой (`STABLE_CHECK_DELAY=2с`).

**Обоснование выбора** (вместо переименования после записи или
файла-маркера готовности): оба альтернативных способа требуют
участия ОТПРАВЛЯЮЩЕЙ стороны — то есть переделки всех текущих и
будущих мест, кладущих пакет в `inbox` (ручной `cp`/`scp`, возможные
будущие скрипты доставки). Проверка стабильности размера работает для
ЛЮБОГО способа доставки файла без чьей-либо кооперации. Цена — до
`STABLE_CHECK_DELAY` секунд задержки перед подхватом нового файла,
пренебрежимо на фоне полного цикла доставки (минуты).

- 10 пакетов `2025`-only (~411 МБ) — декабрь 2025 — апрель 2026, все

**Предложение** (не выполнено — решение за пользователем): переместить
(не удалить) 5 пакетов `2024_2025` в явно подписанную архивную
подпапку (`outputs/dist/_archive_bad_vintage/`, с README) — снижает
риск повторного "случайно взяли не тот файл, похожий по имени"
(именно так начался инцидент round37). Устаревшие `2025`-only тестовые
пакеты можно удалить для освобождения ~411 МБ — решение за
пользователем.
