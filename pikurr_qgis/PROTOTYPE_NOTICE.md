# Статус: прототип, доработка запланирована

Плагин QGIS, разработанный в 2024-2025 годах как прототип доступа к
данным ПИК УРР из настольного QGIS. На момент этой записи — **всё ещё
не доведён до рабочего состояния** (см. ограничения ниже), но остаётся
**основным выбранным путём** доступа из QGIS — не отменяется.

История решения: раунд 46 сначала попробовал заменить плагин доступом
через стандартные службы OGC (WFS) и готовый файл определения слоёв
(`REPIKURR/tools/pikurr_layers.qlr`) — основание было в разборе раунда
45 (`docs/round45-qgis-recon.md`): 5 из 6 функций плагина дублируют
штатные средства QGIS. На практике эта схема **отклонена пользователем**
по итогам раунда 46 (`docs/round46-qgis-route.md`, финальный вердикт) —
неудобная фильтрация по иерархическим группам (область → район →
землепользователь), сложное получение статистики без готовой таблицы,
и растровый слой (AI-оценка) так и не заработал устойчиво до закрытия
раунда. **Решение пользователя — довести плагин** в одном из следующих
раундов; ограничения ниже — карта работы для этого раунда, ещё не
исправлены.

Каталог зафиксирован в git раундом 46 ради истории изменений — до
этого момента `pikurr_qgis/` не был версионирован ни разу
(исключён `.gitignore`), несмотря на то что скачиваемый архив
публиковался с витрины с апреля 2026 года. Кнопка скачивания на
витрине продолжает отдавать этот архив (round46 вернул её после
отклонения WFS/.qlr-схемы).

## Известные ограничения (не исправлены — план работы следующего раунда)

- **Автопоиск сервера ведёт на несуществующий домен.**
  `pikurr.py`, метод `get_geoserver_url()` — пробует `localhost:8080`,
  затем `http://geobotany.xyz` (NXDOMAIN, проверено фактом round45).
  Плагин падает с `Exception('Оба сервера GeoServer недоступны')` до
  показа диалога у любого пользователя без локального GeoServer.
- **Справочник районов жёстко ограничен Витебской областью** —
  словарь `distr` в `pikurr.py` содержит только 20 кодов района,
  начинающихся на `22`. Землепользователь из другой области вызовет
  `KeyError`.
- **`resources.py` жёстко импортирует `PyQt5`**, в обход штатной
  абстракции `qgis.PyQt`, которой пользуется остальной код. На сборках
  QGIS с Qt6 (официальные installer'ы QGIS.org для Windows/macOS,
  начиная с 3.40) импорт этого файла завершится ошибкой.
- Нет тестов, нет `.qrc`-исходника для `resources.py` (только
  скомпилированный `.py`), нет верхней границы версии QGIS в
  `metadata.txt`.

Подробный разбор — `docs/round45-qgis-recon.md` (блоки B, C).
