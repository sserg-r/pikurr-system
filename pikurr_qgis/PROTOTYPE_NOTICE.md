# Статус: прототип, не сопровождается

Плагин QGIS, разработанный в 2024-2025 годах как прототип доступа к
данным ПИК УРР из настольного QGIS. **Не входит в состав текущей
версии продукта** и **не сопровождается**.

Решение (раунд 46): доступ к данным из QGIS обеспечивается стандартными
службами OGC (WMS/WFS) и готовым файлом определения слоёв
(`REPIKURR/tools/pikurr_layers.qlr`), распространяемым через витрину —
см. `docs/round46-qgis-route.md`. Основание — раунд 45
(`docs/round45-qgis-recon.md`): 5 из 6 функций плагина дублируют
штатные средства QGIS, шестая (справочник землепользователей) и таблица
площадей по сценариям воспроизведены через WFS без плагина.

Каталог зафиксирован в git этим раундом ради истории изменений — до
этого момента `pikurr_qgis/` не был версионирован ни разу
(исключён `.gitignore`), несмотря на то что скачиваемый архив
публиковался с витрины с апреля 2026 года.

## Известные ограничения (не исправлялись, решение — не дорабатывать)

- **Автопоиск сервера ведёт на несуществующий домен.**
  `pikurr.py`, метод `get_geoserver_url()` — пробует `localhost:8080`,
  затем `http://geobotany.xyz` (NXDOMAIN, проверено фактом round45).
  Плагин падает с `Exception('Оба сервера GeoServer недоступны')` до
  показа диалога у любого пользователя без локального GeoServer.
- **Справочник районов жёстко ограничен Витебской областью** —
  словарь `distr` в `pikurr.py` содержит только 20 кодов района,
  начинающихся на `22`. Землепользователь из другой области вызовет
  `KeyError`.
- **`resources.py` жёстко импортирует `PyQt5`**, в обход штатной
  абстракции `qgis.PyQt`, которой пользуется остальной код. На сборках
  QGIS с Qt6 (официальные installer'ы QGIS.org для Windows/macOS,
  начиная с 3.40) импорт этого файла завершится ошибкой.
- Нет тестов, нет `.qrc`-исходника для `resources.py` (только
  скомпилированный `.py`), нет верхней границы версии QGIS в
  `metadata.txt`.

Подробный разбор — `docs/round45-qgis-recon.md` (блоки B, C).
