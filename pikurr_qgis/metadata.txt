changelog=1.2.0 (round48):
    - панель (QDockWidget) вместо модального диалога — не блокирует карту;
    - фильтрация по году: "последние данные" (fields_latest) или
      выбранный год (fields + условие года) — раньше все запросы шли
      без учёта года, числа совпадали с прод-данными только потому, что
      на проде один год;
    - "Весь район" — фильтр по атрибуту district, не по префиксу кода
      первого землепользователя;
    - проверка доступности сервера — по содержимому (WPS GetCapabilities),
      не по коду ответа (раньше "доступен" показывалось и для чужого
      сайта без GeoServer);
    - вся сеть — через сетевой стек QGIS (QgsBlockingNetworkRequest),
      не requests — работает с настройками прокси/SSL из QGIS;
    - границы объекта — один запрос вместо двух;
    - слой AI-оценки — через кэш GWC (WMTS), не напрямую;
    - слои — в группе "ПИК УРР", без дублирования при повторном выборе;
    - таблица площадей, копирование в буфер, поиск в списках районов/
      землепользователей.
    1.1.0 (round47):
    - адрес сервера — явная настройка (прод по умолчанию по HTTPS),
      убрано угадывание localhost/несуществующего домена;
    - добавлен уровень "область" к район/землепользователь;
    - справочник названий районов — с сервера, не зашит в плагин;
    - сетевые ошибки и ServiceExceptionReport не роняют диалог;
    - убран сгенерированный resources.py (жёстко требовал PyQt5) —
      иконка и WPS-шаблоны грузятся из обычных файлов (совместимость с
      Qt6 самим этим не проверялась — прямых импортов PyQt5 в коде нет,
      но реальной сборки на Qt6 не было, round48).
    1.0 (2024-2025): первая рабочая версия (не версионировалась явно).
