#🌍️  Установка и использование плагина QGIS «pikurr» (версия 1.1.0)

## Установка

*✅ Установите QGIS Desktop, если ещё не установлен (загрузить можно с ➡️https://qgis.org/download/)
*✅ В QGIS: Модули -> Управление модулями -> Установить из ZIP файла: выберите zip архив устанавливаемого модуля (📁️ pikurr_qgis.zip), 🔳️кнопка: установить модуль
*✅ после установки модуль доступен на панели установленных модулей (значок pikurr)

**❗️ возможно потребуется перезагрузка QGIS

## Использование

*✅ По умолчанию плагин обращается к боевому серверу
   (https://geobotany.of.by) — ничего дополнительно настраивать не нужно.
*✅ Поле «Сервер» в верхней части диалога — только для тех, кто
   разворачивает GeoServer локально для разработки; менять его в обычной
   работе не требуется. Изменённый адрес сохраняется между запусками QGIS.
*✅ Если сервер недоступен, диалог покажет причину под полем адреса и
   останется рабочим — можно исправить адрес и повторить попытку кнопкой
   «Применить».
*✅ Порядок работы: область -> административный район -> землепользователь
   -> «добавить слои». На карту добавляются: подложка (по выбору радиокнопок
   справа — OSM/Esri/AI-оценка), векторный слой полей выбранного
   землепользователя и таблица площадей по сценариям использования снизу.
*✅ Код района/области, отсутствующий в справочнике сервера, отображается
   как есть с пометкой «нет в справочнике» — это не ошибка, а сигнал, что
   справочник названий (REPIKURR/repikurr/src/constants.js) ещё не знает
   про этот код; работу с данными это не блокирует.
