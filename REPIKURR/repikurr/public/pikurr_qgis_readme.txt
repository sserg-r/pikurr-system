#🌍️  Установка и использование плагина QGIS «pikurr» (версия 1.2.0)

## Установка

*✅ Установите QGIS Desktop, если ещё не установлен (загрузить можно с ➡️https://qgis.org/download/)
*✅ В QGIS: Модули -> Управление модулями -> Установить из ZIP файла: выберите zip архив устанавливаемого модуля (📁️ pikurr_qgis.zip), 🔳️кнопка: установить модуль
*✅ после установки на экране появляется панель «ПИК УРР» (можно закрыть/открыть заново значком pikurr на панели инструментов)

**❗️ возможно потребуется перезагрузка QGIS

## Использование

*✅ По умолчанию плагин обращается к боевому серверу
   (https://geobotany.of.by) — ничего дополнительно настраивать не нужно.
*✅ Панель не перекрывает карту и не блокирует работу с QGIS — её можно
   оставить открытой и продолжать пользоваться картой как обычно.
*✅ Порядок работы: **Год** (по умолчанию — «последние данные») ->
   **Область** (можно пропустить) -> **Район** -> **Землепользователь**
   (по умолчанию — «Весь район»). Слой полей, положение карты и таблица
   площадей обновляются сразу при выборе района — отдельной кнопки
   «добавить слои» больше нет.
*✅ Списки района/землепользователя — с поиском: начните печатать
   название или код прямо в поле списка.
*✅ **AI-оценка** — отдельный флажок, не мешает выбору подложки
   (Снимки Esri / OpenStreetMap / нет).
*✅ Таблица площадей — кнопка «Копировать» переносит её в буфер обмена
   для вставки в Excel/Word.
*✅ Раздел «Настройки сервера» свёрнут по умолчанию — разворачивать
   нужно только тем, кто разворачивает GeoServer локально для разработки.
   Изменённый адрес сохраняется между запусками QGIS.
*✅ Если сервер недоступен, сообщение об этом появится в строке
   состояния панели и в панели сообщений QGIS — сама панель останется
   рабочей, можно исправить адрес и повторить кнопкой «Применить» или
   «⟳» у списка годов. Если это боевой сервер — он может быть временно
   остановлен (прерываемая виртуальная машина), восстановление после
   остановки занимает 3-4 минуты, стоит повторить попытку чуть позже.
*✅ Код района/области, отсутствующий в справочнике сервера, отображается
   как есть с пометкой «нет в справочнике» — это не ошибка, а сигнал, что
   справочник названий (REPIKURR/repikurr/src/constants.js) ещё не знает
   про этот код; работу с данными это не блокирует.
