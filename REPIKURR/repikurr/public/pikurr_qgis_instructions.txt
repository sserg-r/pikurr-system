#🌍️ Доступ к данным ПИК УРР из QGIS

Начиная с этой версии данные доступны из QGIS через стандартные службы
OGC (WMS/WFS) и готовый файл определения слоёв — установка отдельного
плагина не требуется.

──────────────────────────────────────────────────────────────────────
1) ОТКРЫТЬ СЛОИ

*✅ Установите QGIS Desktop, если ещё не установлен
   (https://qgis.org/download/)
*✅ В QGIS: Проект → Импорт/экспорт → Импортировать слои из файла слоёв
   (или перетащите файл 📁️ pikurr_layers.qlr в окно QGIS)
*✅ В проект добавятся три слоя:
   - «AI-оценка (текущий год)» — растровая подложка с оценкой ИИ
     (включена по умолчанию, кэшируется на сервере — быстро);
   - «Поля (последний год, WFS)» — контуры полей с атрибутами
     (`nr_user`, `valuation`, `area_ha`); слой запрашивает у сервера
     только те объекты, что попадают в текущую область просмотра карты
     — приближайте карту к нужному участку, полный охват (~56 тысяч
     полей) сервер отдаёт больше минуты и не предназначен для загрузки
     целиком;
   - «Справочник землепользователей» — таблица без геометрии со всеми
     кодами и именами (используется на шаге 2).

**❗️ После открытия проекта подождите несколько секунд, пока слои
полностью подключатся к серверу, прежде чем фильтровать или искать —
сразу после открытия список объектов может быть ещё не загружен.

**❗️❗️ НЕ открывайте таблицу атрибутов слоя «Поля (последний год,
WFS)» напрямую (правой кнопкой → «Открыть таблицу атрибутов») до
фильтрации — ограничение по области просмотра действует только на
отрисовку карты, а не на таблицу атрибутов: она попытается постранично
скачать все 55 784 объекта и будет очень долго грузиться. Сначала
задайте фильтр (шаг 3), потом открывайте таблицу — тогда в ней будут
только отфильтрованные объекты.

──────────────────────────────────────────────────────────────────────
2) НАЙТИ ЗЕМЛЕПОЛЬЗОВАТЕЛЯ

*✅ Откройте таблицу атрибутов слоя «Справочник землепользователей»
   (правой кнопкой по слою → «Открыть таблицу атрибутов»)
*✅ Используйте поиск/фильтр по полю `usname` (имя землепользователя)
*✅ Запомните значение поля `usern_co` в найденной строке — это код,
   он понадобится на следующем шаге

──────────────────────────────────────────────────────────────────────
3) ОТФИЛЬТРОВАТЬ ПОЛЯ И ПОЛУЧИТЬ ПЛОЩАДИ ПО СЦЕНАРИЯМ

*✅ У слоя «Поля (последний год, WFS)»: правой кнопкой → «Свойства» →
   «Источник» → «Построитель запроса» (Query Builder), либо панель
   «Выделение по выражению»
*✅ Условие: nr_user LIKE '<код из шага 2>%'
   (пример: nr_user LIKE '2212000055%')
*✅ Чтобы получить площади по категориям (аналог сводной таблицы):
   Обработка → Инструменты → Векторный анализ → «Статистика по
   категориям» — поле категории: `valuation`, поле значения: `area_ha`,
   источник — отфильтрованный слой (или включите «только выделенные
   объекты»)
*✅ Результат — таблица: количество объектов и суммарная площадь (га)
   по каждому сценарию (`meadow` — луговое, `forest` — перевод в л/х,
   `clearing` — после расчистки, `tillage` — пахотное)
